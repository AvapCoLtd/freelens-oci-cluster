# OCI コマンド連携

> `oci` のラッパや互換コマンドを設定・実装するときに参照する。

[English](oci-command.en.md)

## 設定例

FreeLens を Windows 側、`oci` を WSL 側で実行する構成を想定する。
Preferences の「OCI: oci command」に次の値を設定する。

```text
wsl oci
```

認証情報を注入するラッパがある場合は、そのコマンドを指定する（例: `wsl haj oci`）。
これにより、WSL 側へ OCI 設定ファイルを置かずに実行できる。

プラグインは設定値を空白で分割する。
先頭を実行ファイル、残りを前置引数として `execFile` へ渡す。
クォートは解釈しないため、空白を含む単一引数は指定できない。

## 互換コマンド契約

互換コマンドは渡された引数を `oci` へ転送する。
標準出力、標準エラー、終了ステータスは素通しする。
プラグインが実行する全サブコマンドは[コマンド定義](../src/renderer/cli/command-defs.ts)を単一ソースとし、読み取り操作だけを含む。

### 出力と終了ステータス

- プラグインは全呼び出しへ `--output json` を付ける。標準出力は `oci` と同じ `{"data": …}` 形式にする。
- list 系には `--all` を付ける。
- `--all` を持たない `search resource structured-search` は `--page` でページングし、トップレベルの `opc-next-page` を辿る。
- 手動ページングは最大100ページで打ち切り、超過したセクションだけをエラーにする。
- 終了ステータス0を成功とする。標準エラーへ出力があっても成功として扱う。
- 非ゼロを失敗とし、標準エラーに含まれる `ServiceError:` の JSON から認証、権限・不在、その他へ分類する。

### 実行上限

- 1回の呼び出しは60秒でタイムアウトする。
- 同時に実行するプロセスは最大8件。
- 1回の標準出力は最大64MiB。超過したセクションだけをエラーにする。

標準出力と標準エラーには秘密が含まれないことを契約上の前提とする。
エラー表示には終了ステータスと標準エラーをそのまま出す。
